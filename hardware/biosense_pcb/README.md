# BioSense PCB

## Main modules
- ESP32 / ESP32-S3
- AD8232 ECG
- GSR input
- MLX90614
- MAX30102
- battery measurement
- buzzer
- push buttons
- WS2812 LEDs

## Firmware pin mapping
See `main/include/biosense_config.hpp`.

## Fabrication
Production files for ordered revisions are stored in `fabrication/revX/`.
